# Prime Heroes Wiki

Unofficial pre-launch tracker for **Prime Heroes** (Roblox-exclusive team hero shooter by SuperGaming), built for the `primeheroes.robloxwikihub.com` subdomain.

## Pages

- `/` home hub with verified fact strip
- `/what-is-prime-heroes/` confirmed gameplay structure
- `/release-date/` early access timeline
- `/heroes/` interactive roster explorer (6 slots x 5 ability slots)
- `/prime-universe/` SuperGaming / Indus shared-universe context
- `/news/` verification log with sources
- legal and about pages

## Editorial rule

Only announcement-stage facts from Roblox's newsroom or reputable press. No invented hero names, no leaks, no day-one tier lists. Hero guides land once abilities are playable.
